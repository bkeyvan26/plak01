# ساختار برنامه

کدهای اصلی در ریشه برای سازگاری با اجرای فعلی نگه داشته شده‌اند.
پوشه‌های استاندارد پروژه:

- `templates/` قالب‌های فارسی Jinja
- `static/` فایل‌های CSS و JavaScript
- `tools/` ابزارهای تست و عیب‌یابی
- `tests/` محل تست‌های توسعه‌ی بعدی
- `models/` وزن‌های محلی مدل
- `storage/` تصاویر و متادیتای ثبت‌ها
- `logs/` گزارش‌های اجرایی
